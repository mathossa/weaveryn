# Weaveryn Design Principles

> **Status: Under development.**

This document will eventually expand the interaction and visual-design principles
that guide Weaveryn.

> [!NOTE]
> Older documentation pointed to `README.md` for the high-level design direction.
> That product-direction role has moved to **[Vision 2.0](VISION_2-0.md)**. In
> particular, Vision 2.0 defines character-first entry, session-focused Campaign
> entry, tabbed fixed-viewport pages, and the principle that immersion wins when it
> does not add meaningful friction.

Domain architecture and implementation scope remain governed by
`ARCHITECTURE.md`, `DATA_MODEL.md`, and `MVP.md`.
